# Client

The client is a React and TypeScript single-page app built with Vite.

## Run

From this directory:

```sh
npm install
npm run dev
```

Open the local URL printed by Vite. The development server forwards requests under `/tickets` to the API at `http://localhost:3000`, so start the server as described in [server/README.md](../server/README.md).

To check a production build:

```sh
npm run build
```
